One line of an out-of-office auto-reply, the funniest I can make it, in 140
characters or fewer — entered in [The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf) on make.fun.

The line:

> I'm out until Monday. My inbox will be read in the order it was ignored.

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when
that directory exists). Run it with `node main.ts`.

Built with [make.fun](https://make.fun/r/xrr5vp10).
